# MCP

MCP (Model Context Protocol) servers plug external tools into the agent — databases, APIs, file systems, and custom integrations.

## Setup

1. Open **Settings → MCP**.
2. Add a server: give it a name and the server command or URL.
3. The server's tools appear in the agent's tool list automatically.

## Tips

- Start with one server and confirm its tools show up before adding more.
- Prefer servers with a narrow toolset — every tool costs context.
- If a server misbehaves, disable it here without deleting the config.
